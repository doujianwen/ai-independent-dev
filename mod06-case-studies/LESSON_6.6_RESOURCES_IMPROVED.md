## 4. 法律和商业资源

### 4.1 公司注册

```
选择建议：
├──  solo 开发者 → 个体经营（Sole Proprietorship）
├──  有风险的业务 → LLC（有限责任公司）
└──  有投资人 → C-Corp

中国开发者：
├── 个体工商户 → 简单但无限责任
├── 有限责任公司 → 标准选择
└── 个体户 + 境外收款 → 常见方案

境外收款：
├── Wise — 多币种账户
├── Payoneer — 国际收款
├── Stripe Atlas — 美国公司注册
└── Deel — 跨境薪资
```

### 4.2 必备法律文件

```
独立站必备法律文件：
□ Privacy Policy（隐私政策）
□ Terms of Service（服务条款）
□ Refund Policy（退款政策）
□ Cookie Policy（Cookie 政策）
□ Affiliate Disclosure（联盟披露）

免费生成工具：
├── Termly.io
├── PrivacyPolicies.com
└── Iubenda
```

## 5. AI 辅助资源管理

### 5.1 用 AI 管理知识

```
提示词模板 — 知识整理：

「以下是我本周收集的资料和笔记：
[粘贴内容]

请帮我：
1. 归纳出 5 个关键洞察
2. 找出可以立即行动的建议
3. 生成一个知识图谱
4. 推荐延伸阅读方向」

提示词模板 — 灵感生成：

「基于以下信息，帮我生成 10 个独立产品创意：
- 我的技能：[技能列表]
- 我的兴趣：[兴趣列表]
- 目标用户：[用户描述]
- 市场趋势：[趋势描述]

要求：
1. 每个创意一句话描述
2. 标注开发难度（低/中/高）
3. 标注变现潜力（低/中/高）
4. 标注市场需求（低/中/高）
5. 推荐 Top 3」
```

### 5.2 个人知识库工具

```
推荐组合：
├── Obsidian — 本地 Markdown 知识库
├── Notion — 项目管理 + 知识库
├── Logseq — 大纲式笔记
└── Craft — 美观的文档工具

AI 增强：
→ 用 AI 自动生成笔记摘要
→ 用 AI 连接不同笔记间的关联
→ 用 AI 生成知识图谱
```
