## 1. 搜索引擎工作原理

### 1.1 搜索引擎的三个核心步骤

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   CRAWLING  │ →  │   INDEXING  │ →  │   RANKING   │
│   (爬取)     │    │   (索引)     │    │   (排序)     │
└─────────────┘    └─────────────┘    └─────────────┘
```

**Crawling（爬取）**：
- Googlebot 通过链接发现新页面
- 爬取频率取决于网站权威性和更新频率
- robots.txt 告诉爬虫哪些可以/不可以爬

**Indexing（索引）**：
- 分析页面内容，提取关键词和语义
- 建立倒排索引（Inverted Index）
- 页面质量不够会被排除在索引外

**Ranking（排序）**：
- 用户搜索时，从索引中匹配相关页面
- 根据 200+ 排名信号排序
- 个性化因素：地理位置、搜索历史、设备类型

## 2. SEO 的三大支柱

### 2.1 技术 SEO（Technical SEO）

```
技术 SEO 解决的问题：搜索引擎能不能正确抓取和理解你的网站？

核心要素：
├── 站点结构：清晰的层级和导航
├── 爬取效率：robots.txt + Sitemap
├── 索引控制：canonical + noindex
├── 页面性能：Core Web Vitals
├── 移动友好：Mobile-First Indexing
├── 结构化数据：Schema Markup
└── 安全：HTTPS
```

### 2.2 内容 SEO（Content SEO）

```
内容 SEO 解决的问题：你的内容是否满足用户需求？

核心要素：
├── 关键词研究：找到用户真正搜索的词
├── 搜索意图匹配：信息型/交易型/导航型
├── 内容深度和质量：E-E-A-T 标准
├── 内容新鲜度：定期更新
├── 内部链接：权重传递
└── 多媒体优化：图片/视频 SEO
```

### 2.3 权威 SEO（Authority SEO）

```
权威 SEO 解决的问题：搜索引擎是否信任你的网站？

核心要素：
├── 外链质量：来自权威站点的引用
├── 品牌提及：未链接的品牌提及也是信号
├── 社交媒体信号：间接影响
├── 用户信号：点击率、停留时间、跳出率
└── 域名年龄和历史：长期稳定的域名
```

## 3. 搜索引擎排名信号详解

### 3.1 已知的重要排名信号

```
第一梯队（高权重）：
1. 内容相关性 — 页面内容与搜索 query 的匹配度
2. 外链数量和品质 — 来自权威站点的反向链接
3. 用户体验 — Core Web Vitals + 用户行为
4. E-E-A-T — 经验、专业性、权威性、可信度

第二梯队（中权重）：
5. 页面速度 — 加载速度直接影响排名
6. 移动友好度 — Mobile-First 索引
7. HTTPS — 安全连接
8. 关键词位置 — Title、H1、首段的重要性
9. 内容深度 — 内容的完整性和覆盖面
10. 内部链接 — 站点内的链接结构

第三梯队（低权重/辅助）：
11. 域名年龄 — 新域名需要时间建立信任
12. 社交信号 — 间接影响
13. 地理位置 — 本地搜索的重要因素
14. 搜索历史 — 个性化搜索结果
```

### 3.2 E-E-A-T 深度解析

```
Google 质量评估指南中的 E-E-A-T：

Experience（经验）— 新增！
  内容创作者是否有实际使用/体验该产品的经验？
  例如：产品评测文章应有实际使用截图和感受

Expertise（专业性）
  内容是否由具备相关专业知识的作者撰写？
  例如：医疗文章应由医生撰写

Authoritativeness（权威性）
  网站/作者在该领域是否被视为权威来源？
  例如：行业媒体报道、学术引用

Trustworthiness（可信度）
  网站是否值得信赖？
  例如：清晰的联系信息、隐私政策、用户评价

评分标准（YMYL 页面更重要）：
- YMYL（Your Money Your Life）页面：金融、医疗、法律
  → 评分标准极其严格
- 普通博客页面：评分标准相对宽松
```

## 4. 搜索意图分类

### 4.1 四种搜索意图

| 意图类型 | 特征 | 示例 | 适合的页面类型 |
|---------|------|------|-------------|
| 信息型 | 想知道某事 | "什么是 SEO" | 博客文章、指南 |
| 导航型 | 找特定网站 | "Google 登录" | 品牌着陆页 |
| 商业型 | 比较产品 | "Best CRM 2025" | 评测文章、对比页 |
| 交易型 | 准备购买 | "Buy Nike shoes" | 产品页、电商 |

### 4.2 用 AI 分析搜索意图

```
提示词模板：

「请分析以下关键词的搜索意图，并推荐合适的页面类型：

关键词列表：
- AI 写作工具
- 最好的 AI 工具 2025
- ChatGPT 怎么用
- ChatGPT Plus 价格

对于每个关键词，请回答：
1. 搜索意图类型（信息/导航/商业/交易）
2. 用户期望看到什么内容
3. 推荐的页面类型
4. 竞争度评估（高/中/低）
5. 建议的目标排名位置」
```

## 5. SEO 基础诊断工具

### 5.1 免费工具组合

```
必备免费 SEO 工具：
├── Google Search Console — 索引状态 + 搜索表现
├── Google Analytics 4 — 流量分析和用户行为
├── Google PageSpeed Insights — 性能分析
├── Lighthouse — 综合审计
├── Ubersuggest — 关键词研究（免费额度）
├── AnswerThePublic — 长尾关键词挖掘
└── Screaming Frog SEO Spider — 站点爬取（免费 500 页）
```

### 5.2 基础 SEO 自检清单

```
□ 网站已提交到 Google Search Console
□ Sitemap.xml 存在且可访问（/sitemap.xml）
□ robots.txt 配置正确
□ 全站 HTTPS
□ 每个页面有唯一的 <title> 标签
□ 每个页面有 meta description
□ 图片都有 alt 属性
□ H1 标签每页只有一个
□ URL 结构清晰且语义化
□ 移动端友好
□ 页面加载速度 < 3 秒
□ 404 页面自定义
□ 内部链接结构合理
```

## 6. 常见错误和解决方案

| 错误 | 影响 | 解决方案 |
|------|------|---------|
| 多个页面相同 Title | 自我竞争 | 每个页面唯一 Title |
| 图片没有 Alt 标签 | 图片搜索不收录 | 添加描述性 Alt |
| 死链过多 | 用户体验差 + 权重流失 | 定期检查并修复 |
| 内容重复 | 搜索引擎惩罚 | 使用 canonical 标签 |
| 关键词堆砌 | 被判定为 spam | 自然融入关键词 |
| 忽视移动端 | 60%+ 流量流失 | Mobile-First 设计 |
| 不更新内容 | 排名逐渐下降 | 建立内容更新计划 |
