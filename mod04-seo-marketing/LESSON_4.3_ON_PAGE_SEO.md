# Lesson 4.3: 站内SEO优化

## 学习目标
1. 掌握Title Tag和Meta Description优化
2. 学会Heading标签结构
3. 实战：优化一个页面的SEO

## 1. Title Tag优化
`
- 长度: 50-60字符
- 包含主要关键词
- 独特且有吸引力
- 品牌名放末尾
`

## 2. Meta Description
`
- 长度: 150-160字符
- 包含关键词
- 行动号召
- 不直接排名但影响CTR
`

## 3. Heading结构
`
H1: 页面主标题(只有一个)
H2: 主要章节
H3: 子章节
H4: 详细内容
`

## 4. Schema标记
`json
{
  '@context': 'https://schema.org',
  '@type': 'Article',
  'headline': '标题',
  'author': '作者',
  'datePublished': '2026-07-16'
}
`

## 5. 关键要点
1. 每个页面独特Title
2. 关键词自然融入
3. 内部链接重要
4. 结构化数据加分
