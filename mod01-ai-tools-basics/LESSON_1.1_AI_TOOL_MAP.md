## 1. AI核心技术概念

### Large Language Model (LLM)
- 本质：基于Transformer架构的文本生成模型
- 代表：GPT-4/5, Claude Opus/Sonnet, Gemini 2.5, Llama 3
- 能力：文本生成、代码编写、逻辑推理、多语言翻译
- 局限：幻觉问题、知识截止、无法直接访问实时互联网

### Diffusion Model
- 本质：从噪声逐步去噪生成图像的模型
- 代表：Midjourney v7, DALL-E 4, Stable Diffusion 3, Flux
- 能力：高质量图像生成、风格迁移、图像编辑
- 局限：文字渲染能力弱、一致性控制难

### AI Agent
- 本质：能自主规划、执行、反思的AI系统
- 代表：OpenAI Operator, Claude Computer Use, AutoGPT
- 能力：多步骤任务执行、浏览器操作、API调用
- 局限：稳定性不足、成本高、需要人工监督
