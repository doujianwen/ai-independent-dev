# Lesson 1.2: 高级提示词工程

## 学习目标
1. 掌握CRISPE提示词框架
2. 学会Few-shot、Chain-of-Thought、Tree-of-Thought技巧
3. 能写出高效的System Prompt
4. 实战：用AI生成一份完整的产品需求文档(PRD)

## 1. CRISPE 提示词框架

### C - Clarify (明确需求)
清晰描述你要做什么，避免模糊指令

`
❌ 差："帮我写个产品介绍"
✅ 好："我为一款AI写作助手产品写一段150字的产品介绍，面向自由撰稿人，突出'3倍写作速度'和'零学习成本'两个卖点"
`

### R - Role (设定角色)
给AI一个具体的角色身份

`
"你是一位有10年经验的SaaS产品经理，擅长写用户故事和技术规格文档。请为以下产品撰写PRD..."
`

### I - Input (提供输入)
给出充足的背景信息和约束条件

`
"以下是我的产品信息：
- 产品名称：AI独立开发助手
- 目标用户：独立开发者、自由职业者
- 核心功能：代码生成、Bug修复、文档写作
- 竞品：GitHub Copilot, Cursor, Windsurf
- 差异化：专注于中文用户，支持国内支付..."
`

### S - Scenario (设定场景)
描述使用场景和上下文

`
"这份PRD将用于：
1. 向投资人演示
2. 指导开发团队排期
3. 作为Marketing团队的素材基础
因此需要同时兼顾技术细节和商业价值..."
`

### P - Purpose (说明目的)
告诉AI为什么要做这件事

`
"目的是在3个月内推出MVP版本，验证市场。因此PRD需要：
- 明确MVP范围（不做哪些）
- 标注优先级（P0/P1/P2）
- 给出关键指标（DAU, 留存率）..."
`

### E - Expectation (定义期望)
明确输出格式和要求

`
"请按以下格式输出：
1. 产品概述（200字以内）
2. 用户故事（至少5条，Gherkin格式）
3. 功能清单（表格，含优先级）
4. 技术架构图（Mermaid格式）
5. 里程碑计划（甘特图描述）
6. 风险清单（至少3项）"
`

## 2. 高级Prompt技巧

### Few-Shot Prompting (少样本提示)
给AI几个例子，让它模仿

`
"请将以下句子改写为营销文案。参考示例：

示例1:
输入: '这个工具很快'
输出: '3秒生成，比传统方案快10倍'

示例2:
输入: '这个工具很便宜'
输出: '每月不到一杯咖啡的钱'

现在请改写：'这个工具很好用'"
`

### Chain-of-Thought (思维链)
引导AI展示思考过程

`
"请一步步思考：
1. 首先分析目标用户的核心痛点
2. 然后列出3个可能的解决方案
3. 对每个方案评估优缺点
4. 最后给出推荐方案及理由"
`

### Tree-of-Thought (思维树)
让AI探索多个思路

`
"请从三个不同角度分析这个问题：
角度A：技术可行性
角度B：商业价值
角度C：用户体验
然后综合三个角度给出最终建议"
`

## 3. System Prompt 设计

### 什么是System Prompt？
System Prompt是写给AI的"内部指令"，它定义了AI的行为准则。

### System Prompt 模板

\\\
# 角色
你是一位资深独立开发者，擅长用AI工具快速构建产品。

# 能力
- 精通React/Vue前端开发
- 熟悉Node.js后端和数据库设计
- 了解SEO优化和内容营销策略
- 掌握AI工具的最佳实践

# 行为准则
1. 回答要简洁实用，避免理论堆砌
2. 优先给出可运行的代码示例
3. 遇到不确定的事情要诚实说明
4. 鼓励学员动手实践

# 输出格式
- 代码块必须标注语言类型
- 关键步骤用编号列表
- 重要概念加粗强调
\\\

## 4. 实战：生成PRD

### 任务
为"AI独立开发助手"SaaS产品撰写PRD

### Prompt

\\\
你是一位有10年经验的SaaS产品经理。请为以下产品撰写一份PRD：

产品概述：
- 名称：AI独立开发助手
- 定位：面向独立开发者的AI编程工具
- 目标用户：个人开发者、小型团队(1-5人)
- 核心功能：AI代码生成、智能Debug、自动化文档
- 竞品：GitHub Copilot, Cursor
- 差异化：中文优化、支持国内支付、价格更低

要求：
1. 包含产品概述、用户故事、功能清单、技术架构、里程碑、风险
2. MVP范围限定在3个月内可完成
3. 功能标注优先级(P0/P1/P2)
4. 输出格式为Markdown
5. 总字数控制在2000字以内
\\\

## 5. 练习作业

1. 用CRISPE框架重写你之前写过的3个提示词
2. 为你的课程项目写一个System Prompt
3. 用Few-shot方法让AI生成5条用户评价

## 关键要点
1. **清晰比华丽更重要** — 明确的指令产生更好的结果
2. **给AI角色就是给AI方向** — 角色设定影响输出质量
3. **示例是最好的老师** — Few-shot显著提升一致性
4. **System Prompt是你的产品说明书** — 好的设定事半功倍
