# Module 01: AI 工具入门

## 课程目标
掌握2026年主流AI工具生态，建立"AI-first"工作流思维，能够独立使用AI完成日常开发、写作、数据分析任务。

## 课时列表

### Lesson 1.1 - AI工具全景地图 (45min)
- 什么是AI Agent / LLM / Diffusion Model
- 2026年AI工具分类：写作、编程、设计、数据分析、自动化
- 免费vs付费工具对比表
- 推荐：ChatGPT-5, Claude Opus, Gemini 2.5, Cursor, Windsurf

### Lesson 1.2 - ChatGPT/Claude 高级提示词工程 (60min)
- Prompt Engineering 框架：CRISPE (Clarify, Role, Input, Scenario, Purpose, Expectation)
- Few-shot prompting, chain-of-thought, tree-of-thought
- System prompt 设计技巧
- 实战：用AI写一份产品需求文档(PRD)

### Lesson 1.3 - AI编程助手深度使用 (60min)
- Cursor / GitHub Copilot / Windsurf 对比
- AI代码生成最佳实践
- 调试：让AI帮你找bug
- 实战：用AI从0搭建一个Express.js API

### Lesson 1.4 - AI设计工具：从文本到图像 (45min)
- Midjourney v7 / DALL-E 4 / Stable Diffusion 3
- 提示词写图像的技巧
- 商业图片生成工作流
- 实战：为你的产品生成Banner和图标

### Lesson 1.5 - AI数据分析与可视化 (45min)
- ChatGPT Code Interpreter / Claude Artifacts
- pandas + AI 自动化数据处理
- 用AI生成图表和Dashboard
- 实战：分析一份电商销售数据

### Lesson 1.6 - AI自动化工作流 (60min)
- n8n / Make / Zapier AI集成
- 构建自动化的内容生产流水线
- 定时任务 + AI生成 + 自动发布
- 实战：搭建"每日AI新闻简报"自动化工具

### Lesson 1.7 - AI语音与视频生成 (30min)
- ElevenLabs 语音克隆
- HeyGen / D-ID 数字人视频
- 用AI制作课程视频
- 实战：为你的课程录制一段介绍视频

### Lesson 1.8 - 模块实战：AI工具链搭建 (90min)
- 综合练习：用全套AI工具完成一个小型项目
- 从需求分析 → 原型设计 → 编码 → 内容生成 → 部署
- 产出：你的个人AI工作流文档
