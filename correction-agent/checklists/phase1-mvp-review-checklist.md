## 一、产品打包审查

## 二、定价策略审查

### 2.1 Early Bird  是否有依据？
- [ ] 调研了 Udemy/Coursera/Gumroad 上同类课程的价格带吗？
- [ ]  是否过低（显得廉价）或过高（超出目标用户预算）？
- [ ] 原价  的锚定效应是否合理？

### 2.2 汇率与收款成本
- [ ] 是否计算了 Gumroad 10% 手续费后的实际收入？
- [ ] PayPal 提现到国内银行卡的手续费率是多少？
- [ ] 是否有外汇管制风险（中国个人收美元）？

## 三、交付平台审查

- [ ] PayPal 是否支持中国个人绑定国内银行卡收款？（需核实）
- [ ] 提现周期 7-14 天是否影响现金流？
- [ ] 有没有备用收款方案（以防 Gumroad/PayPal 封号）？

### 3.2 Carrd 着陆页
- [ ] 着陆页是否包含了足够的社会证明（讲师背景、学员评价）？

- [ ] 移动端适配是否良好？
- [ ] 是否有隐私政策和服务条款链接？
