# Module 03: 独立站搭建

## 课程目标
从零搭建一个SEO友好的独立站，并完成部署上线。

## 课时列表

### Lesson 3.1 - 域名与主机选择 (30min)
- 域名注册商对比
- 虚拟主机 vs VPS vs Serverless
- 推荐：Vercel/Netlify + Cloudflare

### Lesson 3.2 - WordPress建站 (60min)
- WordPress安装与配置
- SEO友好主题选择
- 必备插件：Yoast SEO, WP Rocket, UpdraftPlus

### Lesson 3.3 - 静态站点生成器 (60min)
- Next.js/Nuxt.js/Astro对比
- 用AI生成站点结构和页面
- 实战：搭建一个博客站

### Lesson 3.4 - 电商网站搭建 (60min)
- Shopify vs WooCommerce vs 自建
- 支付集成：Stripe/PayPal
- 订单管理自动化

### Lesson 3.5 - 内容管理系统 (45min)
- Headless CMS选择：Sanity/Contentful/Strapi
- 用AI批量生成内容
- 多语言支持

### Lesson 3.6 - 网站性能优化 (45min)
- Core Web Vitals优化
- 图片压缩和懒加载
- CDN配置

### Lesson 3.7 - 网站安全加固 (30min)
- HTTPS配置
- 防DDoS攻击
- 数据备份策略

### Lesson 3.8 - 模块实战：搭建你的第一个独立站 (120min)
- 综合练习：从域名到上线
- 选题：AI工具评测站
- 产出：可访问的网站URL
