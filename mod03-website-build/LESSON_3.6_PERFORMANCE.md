# Lesson 3.6: 网站性能优化

## 学习目标
1. 掌握Core Web Vitals优化
2. 学会图片压缩和懒加载
3. 实战：让网站加载速度提升50%

## 1. Core Web Vitals

### 三个核心指标
- LCP ( Largest Contentful Paint ): < 2.5s
- FID ( First Input Delay ): < 100ms
- CLS ( Cumulative Layout Shift ): < 0.1

## 2. 优化技巧

### 图片优化
`
1. 使用WebP格式
2. 响应式图片(srcset)
3. 懒加载(lazy loading)
4. CDN分发
`

### 代码优化
`
1. 代码分割(Code Splitting)
2. 树摇(Tree Shaking)
3. 缓存策略
4. Gzip/Brotli压缩
`

## 3. 关键要点
1. 性能影响SEO
2. 移动端优先优化
3. 监控要持续
4. 工具:Lighthouse, WebPageTest
