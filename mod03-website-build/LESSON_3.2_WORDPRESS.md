# Lesson 3.2: WordPress建站

## 学习目标
1. 掌握WordPress安装和配置
2. 学会选择SEO友好的主题
3. 实战：搭建一个内容型网站

## 1. WordPress安装

### 推荐主机
- SiteGround (稳定)
- Bluehost (便宜)
- Cloudways (高性能)

### 安装步骤
`
1. 主机控制面板安装WordPress
2. 选择语言和站点名称
3. 创建管理员账户
4. 配置基本设置
`

## 2. 主题选择

### SEO友好主题
- Astra (轻量)
- GeneratePress (快速)
- Kadence (现代)

### 配置要点
`
1. 固定链接结构: /%postname%/
2. 启用SSL
3. 设置头像
4. 配置菜单
`

## 3. 必备插件

### SEO
- Yoast SEO
- Rank Math

### 性能
- WP Rocket
- LiteSpeed Cache

### 安全
- Wordfence
- Sucuri
