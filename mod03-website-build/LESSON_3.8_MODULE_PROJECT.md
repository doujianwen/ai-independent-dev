# Lesson 3.8: 模块实战 — 搭建你的第一个独立站

## 学习目标
1. 综合运用所学，完成网站从0到上线
2. 体验完整建站流程
3. 产出：可访问的网站URL

## 1. 项目选题
AI工具评测站 - ai-tool-review.com

## 2. 开发计划

### Week 1
- Day 1: 域名注册 + 主机配置
- Day 2-3: 站点框架搭建
- Day 4-5: 内容生成
- Day 6: SEO优化
- Day 7: 测试上线

## 3. 技术栈
`
框架: Next.js
样式: Tailwind CSS
CMS: Sanity
部署: Vercel
域名: Namecheap
DNS: Cloudflare
`

## 4. 核心功能
1. 文章列表和详情
2. 分类和标签
3. 搜索功能
4. Newsletter订阅
5. 社交媒体分享

## 5. 关键要点
1. MVP先上线
2. 内容比完美重要
3. 用户反馈驱动迭代
4. 持续优化SEO
