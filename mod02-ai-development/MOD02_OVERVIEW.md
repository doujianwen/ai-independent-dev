# Module 02: AI 辅助开发实战

## 课程目标
学会用AI工具快速构建Web应用、微信小程序、浏览器插件等实际产品。

## 课时列表

### Lesson 2.1 - React/Vue快速开发 (60min)
- 用AI生成完整的React组件
- Tailwind CSS + AI布局
- 实战：搭建一个产品展示页

### Lesson 2.2 - Node.js/Python后端开发 (60min)
- AI生成API路由和数据库模型
- 自动化测试生成
- 实战：搭建RESTful API

### Lesson 2.3 - 微信小程序开发 (60min)
- 用微信开发者工具 + AI
- 小程序云开发集成
- 实战：搭建一个知识付费小程序

### Lesson 2.4 - 浏览器插件开发 (45min)
- Manifest V3 + AI代码生成
- 内容脚本和弹出页面
- 实战：开发一个AI写作助手插件

### Lesson 2.5 - 数据库设计与ORM (45min)
- SQL vs NoSQL选择
- Prisma/Drift AI生成Schema
- 实战：设计电商数据库

### Lesson 2.6 - 部署与CI/CD (45min)
- Vercel/Netlify一键部署
- GitHub Actions自动化
- 实战：搭建自动部署流水线

### Lesson 2.7 - 移动端App开发 (60min)
- React Native/Flutter + AI
- 热更新和OTA
- 实战：开发一个工具类App

### Lesson 2.8 - 模块实战：从0到1构建产品 (120min)
- 综合练习：用AI完成一个完整项目
- 选题：AI写作助手SaaS
- 产出：可运行的产品 + 部署链接
